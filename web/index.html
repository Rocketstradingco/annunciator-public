      Make it yours

      This dashboard monitors your configured machines and services.

      1. Run python3 -m annunciator setup in the source folder to choose your name, color, hosts, services, and optional controls.
      2. Check it with python3 -m annunciator doctor, then start or restart python3 -m annunciator serve after editing config/local.json.
      3. On another device, enter your own server URL in Settings. Android starts with no server configured.
      4. Controls need your own control key in Settings and must be enabled on your server.

      Read the complete setup guide for telemetry, permissions, branding, Android, alerts, updates and troubleshooting.
